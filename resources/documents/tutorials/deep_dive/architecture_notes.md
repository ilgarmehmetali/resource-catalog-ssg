# Static Architecture Patterns

Decoupled static sites offer high speed, top-tier security, and minimal hosting costs.

### Key Benefits
- **Zero Server Maintenance**: No database or backend processes to keep patched.
- **Global CDN Distribution**: Files are served directly from edge locations.
- **Predictable Performance**: Millisecond response times anywhere in the world.
